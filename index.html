Tutorial

Fundamentos del subnetting

Conceptos clave para entender cómo funcionan las subredes IPv4 antes de calcularlas.

¿Qué es una subred?

Una subred (subnet) es una división lógica de una red IP más grande en segmentos más pequeños y manejables. Dividir una red en subredes permite agrupar dispositivos por ubicación o función, reducir el dominio de broadcast, mejorar el rendimiento y aplicar políticas de seguridad independientes a cada segmento.

¿Qué es una máscara de subred?

La máscara de subred es un número de 32 bits que se compara con la dirección IP para determinar qué parte identifica a la red y qué parte identifica al host. Los bits en 1 representan la porción de red y los bits en 0 representan la porción de host disponible para direccionar equipos.

¿Qué significa el CIDR?

CIDR (Classless Inter-Domain Routing) es la notación que expresa la máscara de subred como un prefijo, por ejemplo /24, indicando cuántos bits desde la izquierda pertenecen a la red. Reemplazó al antiguo sistema de clases A, B y C, permitiendo un uso mucho más eficiente del espacio de direcciones IPv4.

¿Cómo calcular una subred?

Para calcular una subred se convierte la IP y la máscara a binario, se aplica un AND lógico para obtener la dirección de red, se identifican los bits de host restantes para calcular el total de direcciones (2^n) y las direcciones útiles (2^n − 2), y finalmente se determina el broadcast invirtiendo los bits de host a 1.

Pasos para calcular una subred manualmente

  1. Escribe la IP y la máscara en binario, octeto por octeto.
  2. Aplica un AND lógico entre la IP y la máscara para obtener la dirección de red.
  3. Cuenta los bits en 0 de la máscara: ese es el número de bits de host n.
  4. El total de direcciones es 2n y los hosts útiles son 2n − 2.
  5. Invierte los bits de host a 1 para obtener la dirección de broadcast.
  6. La primera IP útil es red + 1 y la última es broadcast − 1.

Subnetting

Cómo calcular subredes paso a paso

Una guía práctica con ejemplos reales para dominar el cálculo de subredes IPv4 sin memorizar tablas, entendiendo la lógica binaria detrás de cada resultado.

El cálculo de subredes parece complicado al principio, pero se resume en entender tres cosas: la dirección IP, la máscara y la aritmética binaria. Cuando conviertes la IP y la máscara a binario y aplicas un AND lógico, obtienes automáticamente la dirección de red; el resto es cuestión de contar bits de host para saber cuántas direcciones caben en esa subred.

La práctica recomendada es empezar con ejemplos sencillos, como una red /24, y avanzar poco a poco hacia prefijos menos intuitivos como /27 o /29. Usar una calculadora como SubnetCalc para verificar tus cálculos manuales es una excelente forma de reforzar el aprendizaje sin depender de ella para resolver exámenes.

IPv4 vs IPv6

Diferencias entre IPv4 e IPv6

IPv4 e IPv6 conviven hoy en la mayoría de las redes. Descubre en qué se diferencian, por qué surgió IPv6 y qué implica esto para el subnetting.

IPv4 utiliza direcciones de 32 bits, lo que limita el espacio total a poco más de cuatro mil millones de combinaciones, un número insuficiente frente al crecimiento de dispositivos conectados. IPv6, en cambio, usa direcciones de 128 bits, un espacio prácticamente inagotable para las necesidades actuales y futuras de direccionamiento.

Además de la longitud, cambia la notación: IPv4 se escribe en cuatro octetos decimales separados por puntos, mientras que IPv6 se representa en grupos hexadecimales separados por dos puntos. El subnetting en IPv6 sigue una lógica similar basada en prefijos CIDR, aunque con bloques mucho más grandes por diseño.

Conceptos

Qué es una máscara de red y para qué sirve

La máscara de red es la pieza clave que separa la parte de red de la parte de host en cualquier dirección IP. Te explicamos cómo interpretarla correctamente.

Cada dirección IPv4 va siempre acompañada de una máscara de red, aunque no siempre se muestre de forma explícita. Esta máscara define, bit a bit, qué porción de la dirección identifica a la red a la que pertenece el dispositivo y qué porción queda disponible para identificar hosts individuales dentro de esa red.

Una máscara como 255.255.255.0 equivale a un prefijo /24 y deja los últimos 8 bits para hosts, lo que da 254 direcciones utilizables. Cuanto mayor es el número después de la barra, más bits se destinan a la red y menos quedan disponibles para host, resultando en subredes más pequeñas.
